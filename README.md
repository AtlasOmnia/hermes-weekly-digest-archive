# Hermes weekly digest source archive

Public, source-evidence-only archive for the r/hermesagent weekly user-impact digest about NousResearch/hermes-agent.

Each folder under `archives/` holds one window's GET-only GitHub API snapshot:

- `sources.json`: full reconciled candidate list, search requests, counts, UTC window boundaries, collection time, selected PR evidence and hashes.
- `sources.md`: human-readable rendering of the same snapshot.

Digests link to these files by commit-pinned URL (`/blob/<40-hex-commit>/...` or `raw.githubusercontent.com/.../<commit>/...`) with a SHA-256 of the exact bytes. Branch URLs are not archive references.

A reconciled API snapshot reflects GitHub's index at fetch time; it is not an authoritative audit of all historical merges. No product code lives here.
